# CSV Data Explorer 📊

A beginner-friendly interactive web app built with **Python, Streamlit, Pandas, and Seaborn** to explore CSV datasets and visualize data.

## ✨ Features
- Upload CSV files
- Preview datasets
- Explore basic data information
- Create data visualizations using Seaborn

## 🛠️ Tech Stack
- Python
- Streamlit
- Pandas
- Seaborn

## 🚀 Run Locally

1. Clone this repository.
2. Install the required libraries:

   ```bash
   pip install streamlit pandas seaborn
   ```

3. Run the app:

   ```bash
   streamlit run app.py
   ```

## 🎯 Project Goal
To make basic data exploration and visualization accessible through a simple, interactive interface.

*Built as a learning project in Data Science.*
